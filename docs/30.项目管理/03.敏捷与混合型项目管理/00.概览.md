# 敏捷与混合型项目管理

敏捷项目通过短周期交付、频繁反馈和持续调整应对不确定性；混合型项目则根据交付物、风险与治理要求组合预测型和敏捷型方法。本目录围绕敏捷原则、单团队实践和规模化方法组织知识。

当前内容分为两部分：首先理解敏捷思想、宣言与原则，再比较 Scrum、Kanban、XP 以及多团队和企业级规模化方法。面向PMP考试的生命周期切换与混合治理判断统一收录在“PMP认证备考”模块。

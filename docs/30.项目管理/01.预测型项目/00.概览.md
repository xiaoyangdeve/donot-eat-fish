# 预测型项目

预测型项目在工作开始前明确范围、进度和成本基准，适合需求相对稳定、交付边界清晰或合规约束较强的场景。

本目录按照五大过程组组织：启动、规划、执行、监控和收尾。过程组可以在项目中交叠或重复，并不等同于固定的项目阶段。

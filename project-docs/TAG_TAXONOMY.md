# 标签分类与受控词表

本文档定义全站普通文章的标签语义、命名规则和当前基线。标签用于跨目录聚合相同主题，分类仍由内容目录和 `categories` 承担，两者不可互相替代。

## 使用规则

1. 每篇普通文章使用 2～4 个标签。
2. 标签依次描述核心主题、技术或方法、关键概念，不写完整句子。
3. 中文概念使用简洁、稳定的中文名称；产品、框架、标准和缩写使用官方写法。
4. 不使用作者、转载状态、文章类型、难度或“技术系列”“基本原理”等内部管理词。
5. 不同时保留中英文同义词。新增标签前先复用本词表中的首选名称。
6. 仅当文章正文对概念有实质内容时才设置标签，不根据标题联想扩展无关词。

## 同义词与废弃标签

| 非首选或废弃写法 | 首选写法或处理方式 |
| --- | --- |
| `AB实验`、`AB-Test` | `A/B测试` |
| `Agile` | `敏捷项目管理` |
| `FastText` | `fastText` |
| `技术系列` | 删除，改用实际技术或主题 |
| `基本原理` | 删除，改用具体方法或概念 |
| `大数据` | 删除，改用数据平台、产品或分析主题 |
| `项目管理` | 使用 `预测型项目管理` 或 `敏捷项目管理` |
| `documents` | 仅属于历史分类异常，不得作为标签 |

## 维护检查

新增或修改文章后检查：

- 标签数量是否为 2～4 个。
- 是否存在空值、重复值或同义词并存。
- 官方产品名称和英文大小写是否正确。
- 标签是否能在正文中找到明确依据。
- 是否需要同步扩展受控词表和逐篇基线。
- `npm run verify` 是否通过。
